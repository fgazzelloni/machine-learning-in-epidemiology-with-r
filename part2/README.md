# Part 2 — From Trees to Neural Networks

Planned session: Friday, 23 October 2026, two hours.

Open `part2.Rproj` in RStudio, then open [ml-workflow-2.qmd](ml-workflow-2.qmd).
Keep `part2/` as the working directory.

The draft covers decision trees, random forests, model comparison, neural
networks, unseen-data evaluation and overfitting. It proposes a heart-disease
dataset and uses `mlr3`, `mlr3learners`, `keras3` and `ggplot2`.

## Preparation status
